# 検証レポート（第1回・2026-11-15）

## データと分け方
- JRA公式サイトの結果 6,737レース（2024-12〜2026-11）。障害・オッズ欠けを除いて使用。
- 学習：2025-03〜2025-11（2,572R）／基準決め：2025-12〜2026-05（1,661R）／**採点（未使用）：2026-06〜2026-11（1,521R）**
- 2024-12〜2025-02 は過去走の履歴づくりにだけ使用。

## モデル
- 人気モデル：確定単勝オッズの確率だけ。
- 指数モデル：走破タイム・上がり3Fを「場・芝ダ・距離の基準」と「その日の馬場差」で補正した指数、着順、脚質（1角位置）、間隔、距離・クラス替わり、騎手の直近1年勝率など19項目。レース内で標準化。
- 組み合わせ：人気＋指数。いずれも Plackett-Luce（上位3着）で学習。

## 確率の較正
- 1番人気が3着以内に来ない確率：AIの予測31.6% → 実際33.9%（未使用期間）。帯ごとにもほぼ合う。
  単勝オッズから順に計算した人気モデルは25.2%で、低く出すぎる。
- 3連単1万円以上の確率：AI 69.7% → 実際70.8%。人気モデルは62.0%で低すぎる。
  → アプリの「AIが人気より荒れると見たら荒れ狙い」という条件は、人気モデル側が系統的に低いので意味をなさない。条件を作り直す。

## 次に確かめること
1. 締切前のオッズ（30〜1分前）を毎日ためて、「確定オッズ」ではなく「買える時点のオッズ」で単勝・複勝の候補を採点し直す。
2. 3連単などの推定オッズを、人気モデルではなく実際のオッズ（締切前）と比べて補正する。
3. 指数の作り方の改良（クラス差・斤量・コース形状）は、人気への上乗せがあるかだけで判断する。

# 検証レポート（第2回・2026-11-15）3連複・3連単

## 追加したデータ
- 過去レースの**確定の3連複・3連単オッズ（全組）**：6,574レース。全組の逆数の和から出した払戻率は3連単72.5%・3連複75%で、控除率どおり。
- 期間の分け方は第1回と同じ（採点は2026-06〜11の1,510R、未使用）。同着のレースは除外。

## 確率（各組が当たる確率）の作り方
- 実際のオッズから出した人気の確率、AIの確率（人気＋指数の Plackett-Luce）、単勝人気だけの Plackett-Luce の3つを、学習期間で重みを決めて組み合わせた。
  重み（3連単）：実オッズ 0.86、AI 0.72、単勝人気PL −0.55。AI のうち「単勝の人気から見た上乗せ分」が効いている。

| 当てやすさの上乗せ（実オッズだけと比べて、大きいほど良い） | 基準決め期間 | 未使用期間 |
|---|---|---|
| 3連単 | +0.019（95%: +0.011〜+0.026） | +0.019（95%: +0.011〜+0.026） |
| 3連複 | +0.012（95%: +0.005〜+0.020） | +0.019（95%: +0.011〜+0.026） |

→ 単勝のとき（+0.002、誤差の範囲）と違い、3連複・3連単では前後半とも確かな上乗せがある。
  3連複・3連単のオッズには、単勝のオッズに比べて人気の付き方の偏りが残っていて、そこを補正できている。

## 注意
- 期待値は**確定オッズ**で計算している。実際に買えるのは締切前のオッズで、そこから確定までに動く。
  開催日の取得（締切30〜1分前の3連複・3連単オッズ）がたまったら、「5分前のオッズで選んで、確定の払戻で採点」に置き換えて確かめ直す。これが一番大事。
- 的中は数十回なので、高配当1回で数字が大きく動く。信頼区間の下限は100%を割っている。
